# Sheet 07 — External Graphics AI Prompt

Use this prompt in an external graphics-specialized AI (Midjourney, SDXL, DALL·E) to generate a clear technical isometric assembly image.

## Prompt

Create a clean A4 technical instruction sheet in vector-style infographic format (not photorealistic), showing an isometric cutaway of a papercraft dice tower interior with baffle system assembly.

FORMAT & LAYOUT:
- Vertical A4 page, white background, high print readability.
- Strong visual hierarchy, no clutter, no decorative fantasy art.
- Main title at top: “SHEET 07 — BAFFLE CORE ISOMETRIC ASSEMBLY”.
- Subtitle: “How to mount B1/B2 bulkheads and D1–D6 deflector fins”.
- Keep large margins and clear spacing for print.

MAIN DIAGRAM:
- Isometric semi-transparent tower shell (front and right wall visible).
- Show two internal bulkheads:
  - B1 upper, B2 lower.
  - Each bulkhead has alternating windows (left/right mirrored).
- Show six deflector fins:
  - D1, D3, D5 on left wall.
  - D2, D4, D6 on right wall.
  - Fins folded 30–45° toward center.
- Add a dashed flow path arrow from top entry to bottom exit labeled “DIE FLOW”.

CALL OUTS (with leader lines, non-overlapping):
- “B1 BULKHEAD (upper)”
- “B2 BULKHEAD (lower)”
- “D1/D3/D5 fins on LEFT wall”
- “D2/D4/D6 fins on RIGHT wall”
- “Keep central channel >= 30 mm”
- “Vertical gap B1↔B2: 25–30 mm”
- “Fin fold angle: 30–45°”

BOTTOM STRIP:
- Mini fold example for one fin (flat + fold line + folded direction).
- Technical legend with line coding:
  - CUT = solid black
  - VALLEY FOLD = dashed blue
  - MOUNTAIN FOLD = dotted red
  - GLUE TAB = light gray fill
- 20 x 20 mm scale square in bottom-right corner with label “20 x 20 mm”.

STYLE:
- Crisp black outlines, minimal color accents only (orange for fins, blue/red fold lines, gray glue tabs).
- Sans-serif font, highly legible at print size.
- Avoid overlapping text, avoid tiny labels.
- Engineering infographic aesthetic, vector clean, precise geometry.

NEGATIVE CONSTRAINTS:
- No photorealism
- No textures, shadows, gradients, or cinematic lighting
- No handwritten text
- No fantasy decorations/icons
- No background scene
- No perspective distortion beyond clean isometric technical view
