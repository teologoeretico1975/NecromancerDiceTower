## Workflow

1. Define technical specification.
2. Create A4 SVG template.
3. Export PDF.
4. Print at 100%.
5. Build physical test.
6. Record test notes.
7. Revise template.
8. Add final art.
9. Create color, low ink, and B&W PDFs.
10. Create instructions and Etsy listing assets.

## Important Rules

- Do not use “D&D” in title or main listing.
- Use “tabletop RPG”, “fantasy dice tower”, “printable papercraft”.
- Digital download only.
- No physical item will be shipped.
- No 3D printer required.
- No laser cutter required.
